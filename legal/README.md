## 🌐 Linklarga aylantirish

Privacy Policy va Terms uchun **public URL** kerak. Variantlar:

### Variant 1 — GitHub Pages (TEKIN, eng oson)
1. Repo'yingiz **public** bo'lsa, GitHub'da:
   - **Settings** → **Pages**
   - **Source:** Deploy from branch
   - **Branch:** main, **/legal** papka
   - Save
2. Linklar:
   - `https://azizjan222.github.io/Termiz-taxi/privacy-policy-uz`
   - `https://azizjan222.github.io/Termiz-taxi/privacy-policy-en`

### Variant 2 — Notion (oson)
1. Notion'da yangi sahifa yarating
2. Matnni nusxalang
3. **Share** → **Publish to web** → **Copy link**
4. Linkdan foydalaning

### Variant 3 — Termly.io / iubenda (avtomatik generator)
- https://termly.io — bepul Privacy Policy generator

## 📋 Play Console'ga qo'shish

1. Play Console → **Policy** → **App content**
2. **Privacy Policy** → URL'ni kiriting
3. Save
