# Play Market hujjatlari

Bu papkada Google Play Console'ga yuklash uchun matnlar bor.

## Tuzilma

```
store-listing/
├── passenger/      # Yo'lovchi ilovasi (Sarix Go)
│   ├── uz.md       # O'zbek
│   ├── ru.md       # Rus
│   └── en.md       # English
└── driver/         # Haydovchi ilovasi (Sarix Go Driver)
    ├── uz.md
    ├── ru.md
    └── en.md
```

## Play Console'ga yuklash

1. https://play.google.com/console
2. Loyihangizni tanlang → **Main store listing**
3. Quyidagilarni nusxa olib joylang:
   - **App name** — sarlavhadan
   - **Short description** — qisqa tavsif
   - **Full description** — to'liq tavsif
4. **Add language** orqali boshqa tillarni qo'shing (ru, en)
5. **Save**
