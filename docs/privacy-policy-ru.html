Sarix Go - Termiz Sariosiyo Такси

Последнее обновление: 5 июля 2026

1. Общие положения

Sarix Go - мобильное приложение сервиса такси Termiz Sariosiyo в Сурхандарьинской области, Узбекистан. Эта политика объясняет, какие данные мы собираем и как их используем.

2. Какие данные мы собираем

Данные, которые вы предоставляете:

  • Номер телефона - для регистрации и подтверждения
  • Имя и фамилия - для отображения водителю/пассажиру
  • Фото профиля (необязательно) - для персонализации профиля
  • Языковые настройки
  • Данные заказа - откуда, куда, время, примечания

От водителей (только в приложении «Sarix Go Водитель»):

  • Фото водительского удостоверения (лицевая и обратная стороны)
  • Фото технического паспорта (лицевая и обратная стороны)
  • ПИНФЛ (JSHSHIR) - 14-значный идентификационный номер
  • Данные автомобиля - марка, год, госномер
  • Контактный номер телефона (показывается пассажиру)

Автоматически собираемые:

  • Местоположение (GPS) - только с вашего разрешения, когда приложение открыто
  • Идентификатор устройства

Мы НЕ собираем:

  • Данные банковских карт
  • Список контактов
  • SMS или журналы звонков
  • Личные фото/видео из галереи (кроме загруженных вами фото профиля или документов водителя)

3. Использование данных

  • Предоставление услуг такси
  • Подтверждение номера через SMS
  • Передача заказа водителю
  • Безопасность приложения
  • Поддержка клиентов

4. Передача третьим лицам

  • Yandex Maps - для карт
  • SMS-провайдер (Eskiz.uz) - для кодов
  • Водители - имя, телефон и адрес для заказа

Мы НЕ продаем данные для рекламы.

5. Хранение

  • История заказов - до 2 лет
  • Документы водителя (удостоверение, техпаспорт, ПИНФЛ) хранятся в целях проверки, пока аккаунт активен
  • При удалении аккаунта данные удаляются за 30 дней

6. Безопасность

  • HTTPS-шифрование
  • JWT-аутентификация
  • SecureStore для паролей

7. Ваши права

  • Просмотр данных (в профиле)
  • Изменение (имя, язык)
  • Удаление (запрос через админа)

8. Для детей

Приложение для пользователей старше 18 лет.
